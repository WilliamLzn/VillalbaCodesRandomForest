Machine Learning · UTB 2026-II · Repaso de 5 minutos antes de entrar

Fecha de publicación

9 de octubre de 2026

Fórmulas

Gini de un nodo (con \(p\) = proporción de morosos):

\[G = 1 - p^2 - (1-p)^2 = 2p(1-p) \quad\in [0,\ 0.5]\]

\(p=0\) o \(p=1\) (puro) \(\Rightarrow G=0\); \(p=0.5\) (máxima mezcla) \(\Rightarrow G=0.5\).

Gini ponderado de un corte \(n = n_{\text{izq}} + n_{\text{der}}\):

\[G_{\text{part}} = \frac{n_{\text{izq}}}{n} G_{\text{izq}} + \frac{n_{\text{der}}}{n} G_{\text{der}} \qquad \text{ganancia} = G_{\text{raíz}} - G_{\text{part}}\]

Gana el corte con menor \(G_{\text{part}}\). El umbral de sklearn es el punto medio entre dos valores consecutivos.

Métricas (positivo = mora = 1; matriz con labels=[0,1], ravel() da VN, FP, FN, VP):

métrica fórmula sklearn
tasa base \(\max(p,\,1-p)\) de la prueba (a mano)
exactitud \((VP+VN)/n\) accuracy_score(y_true=..., y_pred=...)
precisión \(VP/(VP+FP)\) precision_score(..., pos_label=1, zero_division=0)
recall \(VP/(VP+FN)\) recall_score(..., pos_label=1)
F1 \(2PR/(P+R)\) f1_score(..., pos_label=1)

KNN (distancia euclídea entre el nuevo \(S\) y cada cliente \(C\) del historial; ganan los \(k\) más cercanos por votación):

\[d(S, C) = \sqrt{\sum_i (S_i - C_i)^2} \qquad z = \frac{x - \text{media}}{\text{desv}} \qquad \texttt{predict\_proba} = \frac{\text{vecinos de la clase}}{k}\]

La media y desviación del escalado se calculan solo con el entrenamiento (y con la desviación poblacional, la de sklearn).

Reglas de oro (donde se pierden puntos)

  1. Hoja empatada (mitad y mitad, p. ej. 1 de 2): predice 0 — es lo que hace scikit-learn y lo dice la actividad.
  2. .ravel() desempaqueta VN, FP, FN, VP (fila por fila de [[VN, FP], [FN, VP]]). Confundirlo intercambia todas las métricas.
  3. Siempre labels=[0, 1] en confusion_matrix para fijar el orden.
  4. El árbol no necesita escalar variables (cada pregunta compara una variable consigo misma); KNN sí (las distancias mezclan escalas).
  5. Árbol sin límite = memoriza (hojas puras) = sobreajuste; con clientes nuevos falla. Brecha entrenamiento-prueba grande = alarma.
  6. Para el banco el error caro es el FN (prestar a quien no paga) → preferir recall sobre precisión.
  7. La actividad compara 3 cortes dados; sklearn prueba todos los umbrales: por eso pueden no coincidir (el ejercicio restringe la búsqueda).
  8. Tasa base = acertar prediciendo la mayoritaria a ciegas. Modelo que no la supera no sirve.
  9. KNN escala, el árbol no: la distancia de KNN mezcla variables de escalas distintas en una sola fórmula (sin escalar, la de números grandes decide sola); el árbol pregunta una variable a la vez.
  10. KNN con \(k\) impar evita empates de votación (2 clases); si aun así empata, sklearn predice la clase 0. predict_proba = proporción de vecinos.
  11. El scaler se ajusta (fit) solo con el entrenamiento y transforma train y prueba: ajustarlo con todo es data leakage.

Código esencial (para copiar del lápiz a Python)

# ---- construir y entrenar (argumentos por su nombre) -------------
from sklearn.tree import DecisionTreeClassifier
arbol = DecisionTreeClassifier(criterion="gini", splitter="best",
                               max_depth=2, min_samples_leaf=5,
                               random_state=0)
arbol.fit(X_train, y_train)                 # estructura en arbol.tree_

# ---- usar ---------------------------------------------------------
arbol.predict(X_test)                      # clases 0/1
arbol.predict_proba(X_test)[:, 1]          # probabilidad de la clase 1
                                            # (= proporción de 1 en su hoja)
export_text(arbol, feature_names=V)        # reglas tipo 'si... entonces'
plot_tree(arbol, feature_names=V, class_names=[...], filled=True)

# ---- métricas (todas con argumentos por nombre) -------------------
from sklearn.metrics import (accuracy_score, precision_score,
                             recall_score, f1_score, confusion_matrix)
VN, FP, FN, VP = confusion_matrix(y_true=y_test, y_pred=clase,
                                  labels=[0, 1]).ravel()
recall = recall_score(y_true=y_test, y_pred=clase, pos_label=1)

# ---- bosque -------------------------------------------------------
from sklearn.ensemble import RandomForestClassifier
bosque = RandomForestClassifier(n_estimators=200, max_features="sqrt",
                                bootstrap=True, oob_score=True,
                                n_jobs=-1, random_state=0)
bosque.fit(X_train, y_train)
bosque.oob_score_          # exactitud 'gratis' con los fuera-de-muestra

# ---- KNN (SIEMPRE escalar; fit del scaler SOLO con train) ---------
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler().fit(X_train)       # 1) fit con entrenamiento
A_train = scaler.transform(X_train)           # 2) transformar train
B_test  = scaler.transform(X_test)            # 3) transformar prueba
knn = KNeighborsClassifier(n_neighbors=5, weights="uniform",
                           metric="minkowski", p=2).fit(A_train, y_train)
knn.predict(B_test)                          # votación de los k vecinos
knn.predict_proba(B_test)[:, 1]               # proporción de votos clase 1

Árbol vs bosque en los argumentos

argumento árbol bosque por qué
n_estimators ✗ no existe 100 (fábrica) cuántos árboles hay
bootstrap ✗ no existe True muestra con reemplazo por árbol
oob_score ✗ no existe False evaluación con los out-of-bag
max_features None (todas) ‘sqrt’ (sorteadas) hace los árboles distintos
max_depth, min_samples_leaf, ccp_alpha, criterion ✓ ✓ (heredados) igual en ambos

Respuestas conceptuales en una línea

  • ¿Por qué Gini? Mide “qué tan revuelta” está la caja: 0 = pura, 0.5 = mitad y mitad. El árbol busca cortes que dejen cajas lo más puras posible.
  • ¿Por qué el bosque funciona? Cada árbol es débil y distinto (bootstrap + variables sorteadas); el promedio cancela sus errores individuales (baja la varianza).
  • ¿Cuándo árbol, cuándo bosque? Árbol para explicar (comité, reglas); bosque para acertar (0.765 → 0.831 en el laboratorio).
  • ¿Qué es OOB? Los ~37% de clientes que un árbol no vio en su bootstrap: una prueba gratuita cuando no hay conjunto de prueba.
  • ¿Por qué KNN escala y el árbol no? La distancia de KNN suma restas de variables distintas en una misma fórmula: sin escalar, la variable con números grandes decide sola. El árbol compara cada variable consigo misma (“¿ingreso ≤ 6.55?”): las escalas nunca se mezclan.
  • ¿Qué hace .fit en KNN? Memorizar los datos (lazy): no aprende parámetros; todo el costo está en .predict (distancias a todos).
  • Efecto de \(k\): \(k=1\) memoriza ruido (sobreajuste); \(k\) enorme vota media cartera (subajuste); impar evita empates en 2 clases.
  • Paper (Kinect): bosque = promedio de las distribuciones de las hojas de \(T\) árboles; entrena con ganancia de información (entropía) sobre candidatos aleatorios; con pocos datos, árboles profundos sobreajustan (prof. ~17 con 15k imágenes), con muchos datos siguen mejorando.
